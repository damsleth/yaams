yaams · autoresearch experiment timeline

Every measured retrieval experiment, in sequence. The line is the accepted baseline — it only advances through kept wins and re-measured baselines. Killed experiments are plotted as floating × markers off the line. Shaded bands mark gold-set eras; metrics are not comparable across bands. Both axes read lower = better — the rate axis is inverted, so every line sinking toward the floor is progress (squint and it's a loss curve).
Markers: ● kept   ○ baseline/anchor   × killed. Hover a point for the full record. The rerank-sweep band uses full rank-1 MRR; earlier bands use partial-credit MRR — different metrics, hence the separate band.
